👆 Vous suivez un loto ? Tapez un numéro pour le pointer quand il est annoncé (re-tapez pour corriger).

Les numéros tirés se cochent tout seuls. La ligne se colore en Quine, Double quine, Carton plein.

🖥️ Deux écrans : laissez le tirage sur cet écran et ouvrez l'Écran de suivi sur l'écran d'à côté — il affiche les cartons qui se cochent en direct, automatiquement synchronisés.

↔️ Déplacez les blocs avec les flèches ◀ ▶ pour arranger l'écran comme vous voulez.
